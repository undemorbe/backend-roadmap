# Лабораторная 10. Оптимизация производительности

Монолит или микросервисы, примерно 1 нед. Открывается после станции «Go изнутри и производительность».

Ускорить свой же код по данным профилировщика и задокументировать каждое изменение.

## Стек

- pprof
- k6
- benchstat
- PGO

## Требования

- Выбери самую нагруженную ручку из лабораторной 3 или 6.
- Сними CPU и heap профили под нагрузкой.
- Каждая оптимизация — отдельный коммит с бенчмарком до и после.

## Этапы

1. Базовые замеры.
2. Три оптимизации по данным профиля.
3. Включение PGO и финальный замер.


## Критерии приёмки

- [ ] p99 снижен минимум на 30%, аллокаций на запрос минимум вдвое меньше.
- [ ] Отчёт в README с flamegraph до и после.
