# Лабораторная 1. Трекер расходов в терминале

CLI, примерно 1 нед. Открывается после станции «Тестирование в Go».

Закрепить основы Go и привычку писать тесты на небольшом законченном инструменте.

## Стек

- Go
- flag или cobra
- encoding/json
- testing
- golangci-lint

## Требования

- Команды `add`, `list`, `delete`, `summary`.
- Поля записи: сумма, категория, комментарий, дата. Деньги храни в копейках (int64).
- Фильтр по месяцу и категории, итоги по категориям.
- Данные в JSON-файле, путь задаётся флагом или переменной окружения.
- Экспорт в CSV.
- Понятные сообщения об ошибках и ненулевой код выхода при ошибке.

## Этапы

1. Доменная модель и хранилище за интерфейсом `Storage`.
2. Команды и парсинг аргументов.
3. Table-driven тесты бизнес-логики и fake-хранилище в памяти.
4. Линтер, Makefile и README с примерами.

## Структура проекта

```
expense-cli/
  cmd/expense/main.go
  internal/expense/      # модель и логика
  internal/storage/      # json, memory
  Makefile
  README.md
```

## Критерии приёмки

- [ ] `go test -race -cover ./...` проходит, покрытие логики не ниже 80%.
- [ ] `golangci-lint run` без замечаний.
- [ ] Повреждённый JSON-файл не роняет программу, а даёт понятную ошибку.
