# Лабораторная 2. Конкурентный веб-краулер

CLI, примерно 1 нед. Открывается после станции «Конкурентность в Go».

Отработать горутины, каналы, context и ограничение нагрузки на реальной задаче с сетью.

## Стек

- Go
- net/http
- golang.org/x/net/html
- errgroup
- x/time/rate

## Требования

- Обход сайта с заданного URL до глубины N, только внутри того же домена.
- Пул из W воркеров, каждый URL посещается один раз.
- Не больше R запросов в секунду на домен.
- Отмена по Ctrl+C через context: краулер дописывает отчёт и выходит.
- Таймауты на запрос, учёт robots.txt.
- Отчёт: карта сайта, битые ссылки, время ответа по страницам.

## Этапы

1. Последовательная версия с тестами на локальном httptest-сервере.
2. Параллельная версия с worker pool и множеством посещённых.
3. Rate limiting, отмена, отчёт.
4. Бенчмарк при W = 1, 4, 16, 64.

## Структура проекта

```
crawler/
  cmd/crawler/main.go
  internal/crawler/
  internal/report/
```

## Критерии приёмки

- [ ] `go test -race` чистый.
- [ ] Нет утечек горутин после отмены (проверь через uber-go/goleak).
- [ ] Тесты не ходят во внешнюю сеть.
