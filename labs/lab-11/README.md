## Требования

- Дизайн-документ: требования, оценка нагрузки, схема, выбор хранилищ с обоснованием.
- Минимум два сервиса или модульный монолит с чёткими границами.
- Деплой на VPS (k3s или docker compose) с HTTPS, CI/CD и наблюдаемостью.
- Публичная документация API и демо.

## Этапы

1. Дизайн-документ и ревью (покажи кому-то опытному).
2. MVP.
3. Продакшен: деплой, мониторинг, бэкапы базы.
4. Презентация проекта в README.
