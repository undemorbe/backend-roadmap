# Лабораторная 8. Отзывы, аналитика и поиск

Микросервисы, примерно 2 нед. Открывается после станции «MongoDB и другие хранилища».

Подключить к маркетплейсу три разных хранилища и синхронизировать их через события.

## Стек

- MongoDB
- ClickHouse
- OpenSearch
- Kafka

## Требования

- Сервис отзывов на MongoDB: отзыв с фото (ссылки на MinIO), рейтинг товара через агрегацию.
- Поиск товаров с опечатками и фильтрами в OpenSearch; индекс обновляется консьюмером событий catalog.
- События просмотров и покупок в ClickHouse; отчёт: конверсия из просмотра в покупку по дням.

## Этапы

1. Сервис отзывов.
2. Индексатор поиска.
3. Сбор событий и аналитический запрос.


## Критерии приёмки

- [ ] Изменение товара появляется в поиске за 5 секунд.
- [ ] Аналитический запрос по 10 млн событий выполняется меньше чем за секунду.

## Со звёздочкой

- Переиндексация без простоя через алиасы индексов.
