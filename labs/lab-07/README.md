# Лабораторная 7. Real-time: трекинг курьера на карте

Микросервис, примерно 2 нед. Открывается после станции «gRPC, WebSocket и real-time».

Real-time и гео в одной задаче: курьеры шлют координаты, клиент видит движение на карте вживую.

## Стек

- Go
- WebSocket
- Redis (Geo и Pub/Sub)
- PostGIS
- Flutter (по желанию)

## Требования

- Курьер отправляет координаты раз в 2 секунды (симулятор на Go, 500 курьеров).
- Клиент подписывается на заказ и получает позицию своего курьера через WebSocket.
- Поиск ближайших свободных курьеров к точке через Redis GEOSEARCH; история треков в PostGIS.
- Работает на двух инстансах сервера, рассылка между ними через Redis Pub/Sub.
- Переподключение клиента без потери последнего известного положения.

## Этапы

1. Приём координат и хранение последней позиции.
2. WebSocket-подписка, один инстанс.
3. Два инстанса за nginx и Pub/Sub.
4. Симулятор нагрузки и замеры.


## Критерии приёмки

- [ ] Задержка от отправки координаты до клиента меньше 300 мс при 500 курьерах.
- [ ] Отключение одного инстанса не обрывает трекинг: клиент переподключается к другому.
- [ ] Нет утечек горутин на закрытых соединениях.

## Со звёздочкой

- Flutter-клиент с картой, плавной анимацией маркера и переподключением.
