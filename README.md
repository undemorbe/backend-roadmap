# Маршрут бэкенд-разработчика на Go

Личный роадмап и курс: теория, тесты, практика и лабораторные — от Linux и SQL до Kafka, микросервисов и system design.

**Сайт:** https://undemorbe.github.io/backend-roadmap/

На сайте: схема маршрута в виде карты метро, страница на каждую станцию (что изучить, практика, материалы, видео, тест с объяснениями), 11 лабораторных с критериями приёмки, экзамен из случайных вопросов и прогресс, который сохраняется в браузере.

## Как устроен репозиторий

```
index.html          сайт (GitHub Pages, без сборки)
assets/             стили и логика
data/modules.js     станции: темы, практика, материалы, вопросы
data/labs.js        лабораторные
data/map.js         схема метро: координаты станций и веток
labs/               описания лабораторных в markdown
notes/              мои конспекты по станциям
scripts/gen-docs.js пересобирает labs/ и таблицу выше из data/
```

Добавить тему или вопрос — правка в `data/`, затем `node scripts/gen-docs.js`.

## Публикация и запуск

```bash
./publish.sh                 # один раз: создаёт репо в GitHub и включает Pages
python3 -m http.server 8000  # локально
# открыть http://localhost:8000
```

## Правила

- Код каждой лабораторной живёт в отдельном публичном репозитории, ссылка — в README лабораторной.
- Тесты с первого дня, CI на каждом репозитории.
- Тест станции не ниже 80% — только тогда дальше.
